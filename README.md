# 📄 WebScan

WebScan is a personal, web-based document scanner built with HTML, CSS, and JavaScript. It allows you to capture images from your device's camera, apply a high-contrast grayscale filter, and download the scanned document as a PDF directly from your browser.

## ✨ Features

- 📸 Access device camera directly from the browser
- 🎨 Apply Grayscale & High-Contrast filters for a scanned look
- 💾 Generate and download PDF files instantly
- 📱 Fully responsive and mobile-friendly
- ⚡ No installation required (Works offline if configured as PWA)

## 🛠️ Technologies Used

- HTML5 & CSS3
- Vanilla JavaScript
- [jsPDF](https://github.com/parallax/jsPDF) (for PDF generation)
